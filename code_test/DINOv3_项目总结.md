## 🚀 如何使用

### 快速开始
```bash
# 激活conda环境
conda activate eomt

# 运行快速入门
python dinov3_quick_start.py

# 运行简单演示
python dinov3_simple_demo.py

# 运行完整演示（包含可视化）
python dinov3_demo.py
```

### 在您的项目中使用
```python
# 导入演示类
from dinov3_simple_demo import SimpleDINOv3Demo

# 初始化模型
demo = SimpleDINOv3Demo()

# 提取特征
features = demo.extract_features("your_image.jpg")

# 计算相似性
similarity = demo.compute_similarity("img1.jpg", "img2.jpg")
```

- **模型**: DINOv3 ViT-L/16
- **参数量**: 300M
- **特征维度**: 1024
- **输入尺寸**: 224×224
- **预训练数据**: LVD-1689M
- **权重文件**: `dinov3_vitl16_pretrain_lvd1689m-8aa4cbdd.pth`
